문제 1.

학생 3명의 이름, 시험점수, 평균을 관리할 때, 기존의 자료형별로 배열을 따로 선언하는 방식 (name[3], score[3]. avg[3])과 구조체를 정의해 사용하는 방식의 본질적인 차이로 가장 옳은 것은?

1. 배열방식은 실수형과 문자형을 동시에 다룰 수 없으나, 구조체는 내부적으로 모든 멤버를 동일한 자료형으로 자동 변환하여 저장한다.
2. 배열 방식은 한 학생의 속성이 서로 다른 메모리 공간에 흩어져 관리되지만, 구조체는 서로 다른 자료형의 데이터를 하나의 논리적 단위로 묶어 한 개체의 데이터가 연속된 메모리 블록으로 응집된다.
3. 구조체를 사용하면 배열과 달리 인덱스를 통한 반복문 처리가 불가능하므로 데이터가 소규모일 때만 제한적으로 사용한다.
4. 배열은 스택 메모리에 할당되지만, 구조체 변수는 선언 위치와 무관하게 항상 읽기 전용 메모리 영역에 할당된다.

문제 3.

C언어의 공용체(union)에 대한 설명으로 옳지 않은 것은?

1. Union 키워드를 사용하여 정의하며, 공용체에 선언된 모든 멤버는 메모리의 시작 주소가 동일하다.
2. 모든 멤버가 동일한 메모리 공간을 공유하므로, 한 멤버에 값ㅇ르 저장하면 기존에 다른 멤버가 저장했던 데이터가 덮어씌워진다.
3. 공용체 전체의 메모리 크기는 선언된 모든 멤버 변수들의 자료형 크기를 전부 합산한 값으로 할당된다.
4. 공용체 변수의 멤버에 접근할 때는 구조체와 동일하게 점(.) 연산자나 포인터를 통한 화살표(->) 연산자를 사용한다.

문제 5.

다음 코드를 보고 Keyboard : 45000이 출력되도록 알맞게 수정한 것은?

--------------------------------------

#include <stdio.h>

struct Item {
	char name[30];
	int price;
};

void sale(struct Item a, int d) {
	a.price -= d;
}

Int main() {
	struct Item p = {"keyboard", 50000};
	sale(p, 5000);
	printf("%s : %d\n", p.name, p.price);
	return 0;
}

--------------------------------------

1. 8번째 행을 struct Item *a로 9번째 행을 a->price -= d;로 , 14번째 행을 sale(&p, 5000);으로 고친다.
2. 8번째 행을 struct Item a[]로, 9번째 행을 a[0].price -= d; 로 고치고 14번째 행은 그대로 둔다.
3. 8번째 행을 struct Item  *a로 ,9번째 행을 *a.price -= d;로 14번째 행을 sale(&p, 5000) 로 고친다.
4. 8번째 행과 9번째 행은 그대로 두고, 14번째 행을 sale(&p, 5000); 으로 , 15번째 행을 p->price로 고친다.
